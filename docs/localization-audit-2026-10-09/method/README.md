# 本次审计方法快照

这些文本保存 2026-10-09 的取样脚本原文，用于复核提取逻辑，不是新增产品入口或正式工具。它们在临时目录执行，未加入项目依赖，也不被安装器/Hook 调用。指纹及临时依赖版本见[取样元数据](../metadata.json)。

快照末尾使用 `.txt`，避免被当作项目可执行脚本。重新取样时，将副本恢复为对应 `.cjs` 名称，按实际仓库和临时工作目录调整内部路径。取样还需要 Node.js（本次 24.13.0）、项目现有的二进制解析依赖，以及临时安装的 Acorn、acorn-walk、parse5；锁定依赖的记录为 `audit-tools-lock.json`。安装官方包时使用 npm pack 的 `--ignore-scripts`，只把包解压到临时目录。

| 步骤 | 脚本快照 | 检查内容 |
|---|---|---|
| 1 | `extract-inventory.cjs.txt` | 复用 Bun 提取器及实际补丁引擎；抽全部 JS 字面量、完整模板/静态段、引用及逐槽状态 |
| 2 | `refresh-source-roles.cjs.txt` | 按语法树刷新角色；排除条件判断和嵌套函数参数继承显示角色 |
| 3 | `augment-symbol-flow.cjs.txt` | 局部词法绑定、有限别名、参数遮蔽及赋值检查；仅作显示消费信号 |
| 4 | `extract-assets.cjs.txt` | 解压非 JS 资源；解析 HTML 节点/属性及脚本，JSON 数据区单独解析 |
| 5 | `sweep-help.cjs.txt` | 复制、补丁临时 Mac 二进制；隔离配置及凭据环境，递归执行 --help |
| 6 | `decision-inventory.cjs.txt` | 精确合并五包候选；标识、模型/协议、归属未确认、短译及模板片段覆盖分别归类 |
| 7 | `focused-decisions.cjs.txt` | 人工选出的重点项目、建议译文及每包容量测算；不会修改产品翻译表 |
| 8 | `method-check.test.cjs.txt` | 7 个抽取边界校验：注释、短词/空白、选择词、嵌套调用、按键对象、变量遮蔽/别名/赋值 |

重新运行第 6 步会将既有生成的 CSV/JSON 移至临时分类快照，再生成新清单；先在独立取样目录复核目标路径，避免移动需要保留的人工文件。本次最后补充的原生运行证据、身份映射过长数量及版本交叉统计分别来自实际运行日志和原始 inventory 复核，不应只靠分类脚本重建。

压缩文件以标准 gzip 保存，解压后分别是 UTF-8 JSON 或带 UTF-8 BOM 的 CSV。原始五包 inventory、全部模块源码和未筛选池格式候选在 `/private/tmp/cczh-deep-audit-20261009/results`；主报告和本目录已经保存实施所需的精炼候选、位置、容量、版本指纹及运行输出。临时目录可能被系统清理，后续应按对应 SHA-256 重新取得官方包。

本方法没有分析完整运行控制流，也没有证明每条候选的屏幕可达性；共享字符串的原生显示引用隔离仍需单独技术验证。计数不能作为全产品汉化百分比。
