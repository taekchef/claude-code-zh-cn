四层本地化，逐层生效。

从设置到二进制补丁，每一层独立工作；任何一层失败，其余层与 Claude Code 本体不受影响。

  1. 一

    中文设置

    合并进 settings.json：界面语言、187 个 spinner 动词与 41 条提示全部中文化，CC Switch 通用配置同步覆盖。

  2. 二

    会话 Hooks

    会话启动时注入中文上下文，让模型以中文回复；桌面通知消息同步翻译。

  3. 三

    输出风格

    内置 Chinese 输出风格，控制 AI 回复的语言与行文习惯。

  4. 四

    CLI Patch

    对 CLI 界面硬编码文字做内容匹配补丁，2065 条翻译按原文精确替换；未识别的文案保留英文，Claude Code 更新后首次会话自动重新补丁。

三十秒安装。

安装器自动完成依赖检查、设置合并与 CLI 补丁；任何时候都可以完整卸载，恢复英文原版。

bash 
curl -fsSL https://github.com/taekchef/claude-code-zh-cn/releases/latest/download/install-remote.sh | bash

卸载：curl -fsSL https://github.com/taekchef/claude-code-zh-cn/releases/latest/download/uninstall-remote.sh | bash

powershell 
git clone https://github.com/taekchef/claude-code-zh-cn.git
cd claude-code-zh-cn
powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1

需要 PowerShell 5.1 及以上（Windows 10/11 自带）。卸载：powershell -NoProfile -ExecutionPolicy Bypass -File uninstall.ps1

bash 
git clone https://github.com/taekchef/claude-code-zh-cn.git
cd claude-code-zh-cn
./install.sh

适合希望跟踪源码、自行修改翻译的用户。
